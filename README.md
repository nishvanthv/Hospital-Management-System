# Hospital Management System

A full-stack Hospital Management System built using:

• HTML
• Bootstrap
• JavaScript
• Node.js
• Express
• Oracle Database

## Features
- Add / Delete Patients
- Add / Delete Doctors
- Book Appointments
- Generate Bills
- Relational Database with JOIN queries

## How to Run

1. Install dependencies:
   npm install

2. Start server:
   node server.js

3. Open:
   http://localhost:3000
